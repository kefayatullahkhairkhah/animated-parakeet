Project overview

A small static project turned into a usable weather application.

Weather Lab is now a live dashboard, not just a demo. It resolves location names through Open-Meteo, shows real weather values, and keeps the selected place across the home and forecast views.

How it works

When you type a city or province name, the app queries the geocoding service and shows matching locations. After you choose one, it loads the current temperature, feels-like value, humidity, wind, pressure, visibility, sunrise, sunset, hourly data, and a seven-day forecast.

Data source

The project uses the free Open-Meteo geocoding and forecast APIs, so it does not need an API key. That makes it easy to run as a static site while still behaving like a real product. Because the search is backed by live geocoding, it can surface multiple locations with similar names, which helps you choose the exact province or city you want.
